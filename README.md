## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/way2masoom/Dev_Portfolio.git
```

### Navigate to the Project

```bash
cd Dev_Portfolio
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
